## Extensions

The barrel exports extensions for build context, bool, collections, colors, date/time, duration, enums, maps, nullable values, numbers, strings, text editing controllers, text styles, URIs, widgets, widget lists, and spacing.

!!! warning
    `lib/src/**` is implementation detail. Application code should import only `package:kite/kite_ui.dart`.
