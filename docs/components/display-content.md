# Display & content

## Card

`KiteCardVariant` supports `surface`, `muted`, and `outlined`.

```dart
KiteCard(
  child: Text('Account summary'),
)
```

## Badge

`KiteBadgeVariant` supports `neutral`, `primary`, `success`, `warning`, `error`, and `info`.

Also available: `KiteAvatar` and `KiteSeparator`.
