# Navigation & layout

Kite includes reusable navigation and information-architecture components:

- `KiteBottomNavBar` with `KiteBottomNavItem`
- `KiteDrawer`
- `KiteAppDrawer` with `KiteDrawerDestination`
- `KiteBreadcrumb` with `KiteBreadcrumbItem`
- `KiteTabs` with `KiteTabItem`
- `KitePagination`
- `KiteAccordion` with `KiteAccordionItem`
- `KiteCarousel`
- `KiteHorizontalListView`

Pair these with the responsive primitives when navigation structure changes between compact and expanded layouts.
