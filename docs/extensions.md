# Extensions

The public barrel exports utility extensions for common Dart and Flutter types.

| Area | Public extensions |
| --- | --- |
| Build context | `BuildContextExtensions`, theme/color/typography/responsive extensions |
| Widgets | `WidgetExtensions`, `WidgetListExtensions`, `NumSpacingX`, `EdgeInsetsX` |
| Text | `StringExtensions`, `NullableStringExtensions`, `KiteTextStyleX` |
| Collections | `IterableExtensions`, nullable iterable helpers |
| Date/time | `DateTimeExtensions`, `NullableDateTimeExtensions`, `DurationExtensions`, `IntDurationExtensions` |
| Values | bool, nullable, number, enum, color, URI, map helpers |
| Forms | `TextEditingControllerExtensions` |

Import only `package:kite/kite_ui.dart`; individual extension files do not need to be imported separately.
